A client only gets the themed card if it asks for one (the 1.14 browser client does). Everything else — vanilla, older versions, the server list API — reads the MOTD as plain text. Choose here what that plain-text rendering should be.

Only used for bands. 1 is a single flat colour; higher values step through more of the 16 classic colours.
